# Sweefl Player 0.3.2 r41：控件可见性与玻璃连续性修复

验证日期：2026-10-25。测试设备：Redmi K20 Pro（raphael），Android 15，arm64-v8a。

## 本次修复

- **控件不可见但仍可点击**：现场确认用户的“实时折射”已关闭。关闭时不创建视频背景采样，而原绘制门控仍要求采样存在，因而吞掉图标和文字。现在组合与绘制共用 `glassContentReady`，关闭效果、纯音频和不支持该采样的 Android 版本不等待不存在的背景。旧 Android 的分支通过源码检查；本次真机为 Android 15。
- **跳转与 loading**：交接期间使用与玻璃相同的固定帧覆盖视频；帧提交后才推进交接。保留用户播放／暂停意图，等待期间持续显示加载圆环。
- **窗口与模糊滑条**：子窗口准备好自身背景后显示；采样支撑区域按模糊范围分档增大，拖动不反复销毁已有背景。首次显示帧人工检查可见折射边缘。
- **进入、退出和比例切换**：同一 Surface 的尺寸变化保留并重新映射有效背景，避免短暂掉入普通透明材料。
- **FFmpeg 暂停画面恢复**：补齐 Renderer 默认方法委托，并修复原生适配层缓存 JNI 局部 Surface 引用的问题。每次绘制取得当前 native window，正确平衡引用；废弃窗口锁定失败不再被当成成功呈现。

## 安装与数据保护

最终手机安装及交付 APK 均为优化的 Release 构建，沿用本机开发证书以兼容覆盖安装，并非商店生产签名。APK SHA-256：

```text
c2a8086a84899c93ebadb1a052e9fd06916fc6268421f6977df24f2528dd5676
```

版本号 0.3.2、versionCode 6 保持不变；r41 为此次交付标识。历史、播放配置、用户偏好均逐文件核对恢复，音量与旋转状态恢复，测试创建的 ADB reverse 已移除，夹具服务已停止。保留用户原来的“实时折射关闭”设置。

完整对应源码包含本次 Kotlin、原生补丁、构建脚本、本地 AAR 和原有第三方源码／许可证。私钥、机器路径配置、用户偏好备份、原始设备转储和大型录像不进入源码包。当前改动未额外推送 GitHub。

构建入口：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "& .\build-local.ps1 -Tasks @('verify', ':app:assembleRelease')"
```
