## 真机验证

设备：型号 `2604FRK1EC`，Android 16 / API 36，CPU `arm64-v8a`，内存页 4096 字节。

普通 USB 安装被系统拒绝。用户明确授权 shell root 后，验证 `uid=0(root)`，通过 KernelSU 的 `su -c pm install -r` 成功安装和更新。未修改系统安全设置，未清空应用数据。**应用本身不需要 root，root 仅用于本次测试设备的安装与自动化输入。**

测试素材：仅录制 Sweefl Player 自身界面生成的 `Movies/Sweefl-UI-Test-01.mp4`，约 23.854 秒、720×1560、屏幕录制默认 AVC，无音轨；未使用、删除或修改用户原有媒体。

## 尚未覆盖

- Android 8–15 设备、16KB 页设备和其他厂商 ROM。
- 全部/部分媒体授权、拒绝与撤销权限的完整矩阵，海量媒体扫描性能。
- 系统文件选择器持久权限跨重启、外部提供方差异。
- HEVC / AV1 / HDR、多音轨与内嵌字幕的实际媒体兼容性。
- 音频焦点、耳机插拔、电话打断、不同音频编码；本次素材无音轨。
- 长时播放、耗电、温升、掉帧、内存压力和进程被系统回收。
- 完整无障碍测试、正式发布签名、商店审核。

本版为可继续开发和真机体验的第一版，不作为已经完成全格式播放器或 MPC-HC Android 移植的证明。
