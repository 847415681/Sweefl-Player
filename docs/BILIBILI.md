# Bilibili 与网络选轨

本次实现参考 [BilibiliPotPlayer](https://github.com/frostnotfall/BilibiliPotPlayer) 的公开网页播放协议，使用本项目的 Kotlin/Media3 架构独立实现；没有复制其完整播放器解析器。

## 输入和能力

网络地址支持 BV/av 视频页面及分 P、b23.tv 短链接、番剧 ep/ss 页面、直播间。输入层也能从 B 站分享文字中提取链接。历史记录使用稳定页面地址，不保存短期 CDN 播放地址或 Cookie。

实时控制栏按可用能力显示：

- **选集**：实际返回多个分 P、合集条目或剧集时显示。
- **清晰度**：存在多个实际返回的视频画质时显示；不把接口公布但没有返回播放流的画质当成可选项。
- **音轨**：存在多个独立音频流时使用在线源目录；没有独立音频目录时，使用 Media3 检出的多个受支持音轨，包括直播 HLS 内置音轨。
- 普通 HLS/DASH 使用 Media3 的受支持轨道列表，可恢复自动选择。原有“字幕与音轨”入口仍保留。

视频 DASH 的单文件 SegmentBase 视频与独立音频在同一个播放器中合并。单个 durl 可播放；多个连续 durl 片段目前明确提示不支持拼接。番剧、地区、登录和会员能力由服务端响应决定；账号相关功能通过应用内官方登录页面使用。

## 直播时移

时移能力由实际 fMP4 HLS、直播能力标记和进度条接口共同确定。界面使用服务端声明的回看范围，不把 Media3 数秒的 HLS 播放列表窗口伪装成长时间 DVR，也不扩大服务器公布的范围。

拖动使用 Long 绝对时间；只有相对于冻结窗口的滑块距离使用 Float。按下时冻结范围，松开时按最新可用范围裁剪目标。回看通过正整数 `tmshift` 重建历史流；同源、限定目录中的历史播放列表及初始化/媒体分片继承该参数。返回直播移除参数，不发送 `tmshift=0`。

切换清晰度保留回看内容位置及播放/暂停意图。暂停时保存内容时间，继续播放时重新计算延迟，避免等待期间目标跟随直播端前移。后台恢复及过期地址失败有有限的重新解析机制。

该类 fMP4 播放列表没有 `EXT-X-PROGRAM-DATE-TIME`；时间映射结合请求目标、播放列表时长和滑动窗口偏移，不能承诺逐帧墙钟对齐。超出可回看范围时定位到最早可用内容并提示。

## 登录、请求与生命周期

官方登录使用应用私有 WebView Cookie 存储，不提供 JavaScript 原生桥。只向精确 HTTPS Bilibili API 主机发送 Cookie，不向媒体 CDN、字幕或一般网络来源发送。退出登录只清理本应用网页登录状态。

VOD/PGC API 与媒体请求使用兼容的桌面浏览器 UA 和站点根 Referer；直播继续使用独立的 Mobile UA 与直播间 Referer。从每个资源的 API 原始及备用地址中优先选取非 P2P CDN，识别包括主机特征和 `os=mcdn` 标记。保留其余候选与原始签名 URL，不自行替换主机或改写签名查询。上述请求头、候选排序及原始地址保留契约有回归测试，并经真实点播解码验证。

解析任务属于 Activity 会话，取消旧请求并用序号拒绝迟到结果。获取新源时保留当前播放，解析成功后才替换播放器。已失败的选择与生命周期取消的请求分开保存；关闭错误提示后，后台恢复不会再次强制加载失败选择，旧源自动恢复也不会取消正在解析的新选择。

首次把分享别名解析为稳定页面时，按稳定键读取历史与字幕/渲染配置，明确保存的播放位置保持优先；既有 URI SHA-256 规则不变。分集切换读取该集设置，选画质/音轨保留当前设置。登录流程禁止自动进入画中画，并保存流程标记。

诊断继续使用 `schemaVersion=1`，增加可选 `online` 状态：源类型、实际画质/集数/音轨数量、时间范围、逻辑位置、实际 shift 和暂停位置。它不记录签名媒体 URL 或 Cookie。

已通过 `verify`（架构检查、app/domain 单元测试、Debug、lint）及 Release 构建。实际设备为 Redmi K20 Pro / Android 15 / arm64-v8a。

设备测试经 `tools/guarded_v032.py` 保存/恢复三份偏好、音量、旋转及自建 ADB reverse。原始失败与复测分别保存于忽略的 `docs/testing-r43-online/attempt*` 目录；不要把用户媒体库截图或带签名的网络材料加入发布源码。

直播滑块测试使用 `tools/slider_gesture_driver.py` 的独立 UiAutomation 工装。它保留同一手势的 downTime 和 pointer ID，读取真实触摸阈值与 RangeInfo，在 UP 前确认选中目标；不能仅用 ADB swipe 的终点推算滑块值。此前坐标测试实际进入历史流，但因触摸阈值产生目标偏差而未通过断言，失败证据保留。

未验证真实账号登录后的付费权益，也未进行 B 站回看进程被系统终止后的重建测试；旋转与后台恢复是在同一进程、原任务内验证。音轨验证依据解码器及输入格式，未做 PCM/听音测量。不把这一台设备的结果泛化为所有编码和设备。
